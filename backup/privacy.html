ITIGRE Backup 隱私權政策

更新日期：2026 年 11 月 10 日

本政策適用於 ITIGRE Backup 個人備份工具，由 ITIGRE 管理者使用，處理其自行管理或已取得授權的專案與雲端資料。

資料與使用目的

工具會處理選定的 GitHub 儲存庫內容、提交歷史及另外啟用匯出的專案資料，產生備份檔、清單與驗證資訊。Google Drive 授權用於讀取指定路徑的資料夾與檔案資訊、建立及上傳備份、下載驗證或還原資料，以及在啟用保留期限管理後刪除該備份路徑中的到期副本。

Google Drive OAuth 若使用完整存取範圍，技術權限包含讀取、建立、修改與刪除檔案；程式應僅對指定備份路徑執行作業。OAuth 憑證與更新權杖用於維持自動備份連線，不應寫入公開原始碼或記錄。

儲存與處理服務

備份目的地為管理者指定的 Google Drive 與 Koofr 帳戶；若採用 GitHub Actions，執行期間亦會在 GitHub 提供的執行環境中暫時處理資料。各服務依其自身條款及隱私權政策處理資料。

本工具不出售 Google 使用者資料、不將其用於廣告，也不將其用於訓練通用人工智慧模型。資料僅用於管理者授權的備份、驗證、還原及維護工作。

保存與刪除

備份保留期限依實際啟用的設定決定。目前規劃保留最近八週的週備份，以及最近十二個月的月備份；未完成驗證前不應自動清理舊副本。管理者可在兩個目的地分別刪除備份；服務提供者的垃圾桶或版本保存機制可能仍保留副本。

撤銷授權與安全

管理者可隨時前往 Google 帳戶的第三方連線設定撤銷 ITIGRE Backup 授權，並停用備份排程及刪除已保存的憑證。撤銷授權不會自動刪除先前備份的檔案。

憑證應保存於 GitHub Actions Secrets 等受存取控制的設定中。此政策不表示系統已完成首次備份或加密設定；相關狀態以實際執行及驗證結果為準。
