Canon EOS R7 / SETTING REVIEW

2026-09-14

CAMERA NOTES / CANON EOS R7

三組設定就夠用，先拍到，再慢慢調。

這篇是自己的 R7 隨身速查表。用 C1 拍人、C2 拍舞台、C3 拍腳架夜景。第一次設定花幾分鐘，之後只要轉模式轉盤、確認快門，就可以開拍。

機身 Canon EOS R7｜常用鏡頭 SIGMA 16–300mm F3.5–6.7 DC OS（RF 接環）。以下是試拍起點，不是 Canon 原廠預設值。

02 / CONTROL

相機拿起來，先認識這五個位置

  1. MENU開啟選單，登錄 C1／C2／C3 就從這裡進去。
  2. 多功能控制器＋外圈轉盤拇指移動對焦點、轉動設定值；是 R7 最值得熟悉的操控區。
  3. AF-ON啟動自動對焦；追拍時可按住。若沒改自訂按鍵，半按快門同樣能對焦。
  4. INFO切換拍攝資訊；開選單時也能切換設定頁組。
  5. Q/SET（十字鍵中央）拍攝時叫出速控選單；在選單內用來確認。

機頂模式轉盤則負責切換 Tv／M 與登錄後的 C1／C2／C3。沒有必要一開始就改全部自訂按鍵，先沿用半按快門對焦即可。

03 / SAVE

把三組設定存進 R7（一次做好）

  1. 先做 C1：機頂轉到 Tv，照上面的 C1 卡片設定快門、Auto ISO、Servo AF。
  2. 按 MENU：進入黃色「設定」→「自訂拍攝模式(C1–C3)」→「註冊設定」→「C1」→「確定」。
  3. 做 C2、C3：各自先轉一般的 M 模式，把對應參數調好，再分別註冊到 C2、C3。
  4. 轉回試拍：依序轉到 C1、C2、C3，檢查快門、ISO、AF 與防手震是否符合預期。

建議把「自動更新設定」保持在停用，現場微調後不會不小心改掉原本的基準。要永久修改，就重新註冊。

04 / FIX

照片拍不好？只檢查這四件事

人糊掉

先提高快門：1/250 → 1/500 → 1/1000 秒。IS 不能讓跑動的人停住。

臉清楚，但照片太暗

看看 Auto ISO 是否已到上限、鏡頭光圈是否已全開；舞台燈光變化大，拍一張檢查高光。

對焦跑到背景

確認 Servo＋人物／眼睛偵測；用拇指移動對焦區，重新指定主角。

夜景整張都晃

手持要開 IS 並提高快門；上固定腳架則用 C3、2 秒自拍，SIGMA 16–300 的 OS 依手冊關閉。

少數例外：手持夜景、搖攝、舞台 LED 橫紋

沒有腳架的東京鐵塔：不要直接沿用 C3 的 2 秒曝光。改 M＋Auto ISO、廣角先試 1/60 秒、開最大可用光圈、IS ON；長焦必須再提高快門。

想讓車流背景拉出線條：用 C1／Tv，把快門暫時降到約 1/60 秒，跟著車平順轉動；拍完立刻恢復 1/500 秒。

舞台 LED 橫紋：先使用機械快門、視情況啟用防閃爍並試拍；不是把對焦追蹤靈敏度改成負數就能修好。

SIGMA 16–300mm 注意：鏡頭上的 LOCK 是變焦鎖，不是防手震開關；OS 的開關從相機端設定。長焦端最大光圈是 f/6.7，無法直接設 f/3.5。

參考與使用範圍

這是照片拍攝的個人實務速查，不是原廠情境參數。機身功能與按鍵名稱依 Canon 官方說明書；SIGMA 的防手震與變焦鎖操作依鏡頭使用說明書。不同鏡頭與光線，仍要以試拍結果調整。
